# 서가 라벨(청구기호) 출력 안내

집 서재의 공간 › 책장 › 칸마다 이름과 코드를 붙인다(설정 › 위치). 책마다 **청구기호 라벨**을 붙이면 서재가 정리된다.

- **청구기호**: 위치 코드 + 칸 안 순번. 예: `LV-B2-S3 · 07` = 거실 › 2번 책장 › 3칸의 7번째 책.
- **라벨 구성**: QR(책 상세로 이동) · 청구기호 · 짧은 제목 · 관리번호(`HL-000123`).
- **칸 이름표**: 선반 앞면에 붙이는 큰 위치 코드. 구역은 흑백 띠로 표시한다.

## 사용 순서(`/labels`)

1. **범위 고르기**: 집 전체 · 공간 · 책장 · 칸.
2. **칸 순서 정하기**: 지금 순서 유지 / 제목순 / 저자순 / 분야→제목순 / 시리즈·권차순.
   - 새로 등록하거나 옮긴 책은 그 칸의 맨 뒤 번호를 자동으로 받는다.
3. **출력**
   - **인쇄 창(기본)**: 새 탭에서 라벨 한 장 = 한 페이지로 열린다.
     - 블루투스로 페어링한 라벨 프린터(드라이버 필요)나 'PDF로 저장'을 고른다.
     - 용지는 라벨 크기, 여백 없음, 배율 100%.
     - 출력한 뒤 '인쇄 완료로 표시'를 누른다.
   - **Niimbot 블루투스 직접 출력(실험적)**
     - PC·안드로이드 Chrome/Edge 에서 **HTTPS 주소**로 열었을 때만 쓸 수 있다(웹 블루투스).
     - 한 장 출력할 때마다 자동으로 완료가 기록된다.
4. **붙이기**: 출력 순서대로 붙이고 같은 순서로 칸에 꽂는다.
5. **다시 뽑기**: 책을 옮기거나 순서를 바꾸면 '다시 뽑을 라벨'로 나온다.

## 추천 하드웨어

| 용도 | 권장 |
|---|---|
| 프린터 | **Niimbot B1** — 블루투스, 폭 20~50mm 감열 라벨, 203dpi(8 dot/mm). 저렴하고 웹 블루투스 직접 출력을 지원한다 |
| 책 라벨 | 50×30mm 또는 40×30mm(뒤표지·앞면지), 40×20mm(책등 아래), 30×15mm(얇은 책등: 청구기호 + QR) |
| 칸 이름표 | 50×30mm. 감열 라벨은 햇빛·열에 바래므로 오래 붙일 이름표는 바래지 않는 라벨지를 권한다 |
| 그 밖의 프린터 | Brother QL·PT(블루투스) 등 OS 드라이버가 있는 프린터는 '인쇄 창' 경로로 쓴다 |

## 주의

- **QR 주소**
  - 라벨에 영구히 남는다. 운영에서는 `LABEL_QR_BASE`(또는 `APP_URL`)를 바뀌지 않을 공개 주소로 정해 둘 것.
  - `APP_URL` 이 localhost 이면 지금 접속한 주소를 쓴다.
  - 짧은 주소 `/c/{관리번호}` 는 로그인과 서재 소속을 확인한다. 다른 가구 사람이 찍으면 404.
- **블루투스 라이브러리 라이선스**
  - `@mmote/niimbluelib`(MIT)는 README 에 "교육 목적, 제조사 동의 없는 상업적 이용은 의도하지 않음"이라고 적혀 있다.
  - 서비스를 수익화하기 전에 이 기능의 유지 여부를 재검토한다. 기본 경로(인쇄 창)는 영향이 없다.
- **아이폰**: 웹 블루투스를 지원하지 않는다. 인쇄 창에서 PDF로 저장한 뒤 프린터 제조사 앱으로 출력한다.
- **검증 범위**: 실물 프린터로 시험하지 않았다. 캔버스 렌더링과 인쇄 페이지(PDF)까지 확인했다.
