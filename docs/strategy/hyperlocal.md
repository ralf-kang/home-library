# 동네 단위 차별화 전략 (요약)

> 2026-10-04 작성. 전체 리포트(표·흐름도·출처): https://claude.ai/artifact/R4rCsH5eoimDwoLLz1vMPi
> 경쟁사 수치와 법 해석은 공개 자료 기준이며, ⚠️는 확인되지 않은 항목이다. 법률 자문이 아니다.

## 핵심 판단

- **동네라는 범위 자체는 차별점이 아니다.** 「우리집은도서관」(스파이더랩, '우도')은 2020년 바로 이 모델로 시작했다.
  - 초기 모델: 이웃 간 직접 대여, 권당 900~1,500원 대여료에서 수수료를 정산
  - 2021년 전국 택배 대여·위탁·판매로 전환했다
- 차별점은 **동네에 공유할 책이 충분히 모이는 구조**다.
- 원칙: **무료·무중개, 가정 서재 정리를 입구로**.

## 동네 직거래가 어려운 이유 (추정)

1. **밀도**: 서재당 책이 적고, 걸어갈 거리 안에서 원하는 책을 찾을 확률이 낮다.
2. **동기**: 빌려주는 쪽은 수고만 있고 얻는 것이 적다.
3. **반납**: 우도 리뷰의 주요 불만이 반납·상태 갱신 오류다.
4. **사용 빈도**: 빌릴 일이 없으면 앱을 열지 않는다.

## 설계

### 포지셔닝

- **"우리 집 책장을 정리하면, 동네 책장이 됩니다."**
- 1차 타깃: 초등 이하 자녀를 둔 아파트 단지 가정. 그림책·전집은 돌려 읽기 수요가 크다.

### 클러스터

- **단위**: 학급·학교 → 아파트 단지 → 행정동 → 이웃 동. 가장 작은 단위에서 시작한다.
- **개장 조건**: 참여 5가구 이상, 대여 가능 책 150권 이상(조정 가능). 그전에는 대기 화면을 보여 주고 초대를 유도한다.
- **참여 방식**
  - 초대 링크(구현됨)
  - 단지·학급 코드(1단계)
  - GPS 인증(3단계, 위치기반서비스사업 신고 뒤)
- **공개 범위**: 동·단지 이름까지만 공개하고, 정확한 주소는 수집하지 않는다.

### 대여 흐름

요청 → 승인 → 약속(장소 추천) → **QR 인계 확인** → 반납 알림 → **QR 반납 확인** → 반납 준수 기록

- **신뢰 장치**
  - 책 매너: 제때 반납률·상태·응답
  - 신규 가구 대여 권수 상한
  - 책마다 대여 조건(기간, 직접 수령만, 전집 묶음, 아이 책은 어린이 가구에만)
- **분쟁 처리**: 당사자 해결이 원칙이고, 플랫폼은 기록만 제공한다.
- **넣지 않는 것**: 보증금·대여료. 넣으면 통신판매중개 의무가 생길 수 있다.

## 차별점

| 차별점 | 상태 |
|---|---|
| 가정 서재 위치 관리 | 있음 |
| 청구기호 라벨·라벨프린터·칸 이름표 | 개발 중 |
| 가족 역할·아이 대리 기록 | 있음 |
| 무상 대여 + QR 반납 추적 | 대여는 있음, QR은 1단계 |
| 단지·학급 클러스터 | 1단계 |
| 공공도서관 소장·대출 가능 연계 | 구현됨(키 대기) |
| 전집 순환·다음 전집 매칭 | 2단계 |
| 동네 무인 공유 책장 | 3단계 |

**'사기 전에 빌리기' 사슬**: 우리 집 → 이웃 서재 → 근처 공공도서관 → 구매 링크

## 로드맵

| 단계 | 내용 |
|---|---|
| 1 (4주) | 라벨·QR, 단지·학급 코드, 개장 조건, 대여 메시지·약속, QR 인계·반납, 반납 알림, 사기 전에 빌리기 |
| 2 (시범 단지 이후) | 책 매너, 전집 묶음 대여·물려주기, 다음 전집 매칭, 동네 북클럽·교환 장터, 문화행사 공공데이터 |
| 3 (확장) | GPS 동네 인증(신고 후), 행정동 공개 참여, 무인 공유 책장, 도서관·지자체 협력 |

**시범 성공 지표**(단지 1곳, 8주)
- 참여 20가구
- 공유 책 600권
- 월 대여 40건
- 정시 반납률 90% 이상
- 4주 유지율 60% 이상

## 규제 메모

- **위치정보법**
  - GPS 좌표를 서버로 보내 쓰면 신고 대상이다.
  - 소상공인은 사업 개시 후 1개월 안에 신고할 수 있다.
  - 1단계는 GPS 없이 진행한다.
- **만 14세 미만**: 위치 기능을 빼고, 동네 인증은 보호자만 한다.
- **전자상거래법**: 무상 대여는 중개 의무 대상이 아닐 가능성이 크다(⚠️). 유상 요소는 넣지 않는다.
- **브랜드**: 「우리집은도서관」과 이름이 비슷하므로 상표 검색이 필요하다.

## 결정 필요

1. 시범 단위(단지 vs 학급)
2. GPS 인증 시점
3. 무상 원칙을 약관에 명시할지
4. 서비스명
5. 공공 API 키 발급
