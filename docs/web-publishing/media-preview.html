가족의 서재 → 독서 기록 → 이웃과 책 나눔. 랜딩의 사용 방법 앞뒤에 배치하는 12초 소개 영상입니다.

영상 대본과 사용 위치
  1. 0~4초: 집 안의 책을 한곳에 모아 우리 가족의 서재를 만듭니다.
  2. 4~8초: 완독과 별점, 마음에 남은 문장을 가족의 독서 기록으로 남깁니다.
  3. 8~12초: 나누고 싶은 책을 공개하고 동네 이웃과 함께 읽습니다.

사용 페이지: /, /#how. 첫 화면의 히어로 이미지와 동시에 자동 로드하지 않습니다.

02 · 사진 등록, 세 단계

정면 촬영 → 판독 목록 확인·수정 → 확인한 책 등록. 사진 업로드 전에 보는 짧은 사용 안내입니다.

MP4 다운로드WebM 다운로드

포스터 표시 중 · 재생을 누르면 영상을 불러옵니다.

video/add-photo-three-step-guide-720p.{mp4,webm}
영상 대본과 사용 위치
  1. 0~4초: 밝은 곳에서 책장 한 칸의 책등 전체를 정면으로 촬영합니다.
  2. 4~8초: 판독한 제목·ISBN·중복 여부를 수정하고 책 위치를 확인합니다.
  3. 8~12초: 검토한 책만 등록하고 서버 저장 완료를 확인합니다.

사용 페이지: /add/photo, /#how. 오류나 로딩 화면에서는 성공 예시를 실제 완료 상태로 보여주지 않습니다.

개발 적용

사진은 Next.js static import로 사용합니다. 영상은 필요한 파일을 src/img/video에서 public/img/video로 복사한 뒤 연결합니다. 현재 실행 중인 앱에는 아직 반영하지 않았습니다.

화면에 핵심 한국어 문구가 포함되어 있습니다. 선택 자막 VTT를 사용할 때는 영상과 자막을 같은 HTTP 출처에서 제공하세요. 로컬 파일로 열 때 자막 로딩이 제한되면 펼쳐보기 대본을 이용할 수 있습니다. 동작 줄이기 설정에서도 명시적으로 재생하기 전까지 정지 포스터를 유지합니다.
